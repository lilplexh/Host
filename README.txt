Game Show MVP — Windows (created by script)

How to run:
1. If Node.js is not installed, the script will open the Node.js website.
2. After installing Node.js (LTS), run this script again in PowerShell.
3. When the server is running, open http://localhost:3000 in your browser.
4. To invite friends on the same Wi-Fi, share your local IP, e.g. http://192.168.1.23:3000
